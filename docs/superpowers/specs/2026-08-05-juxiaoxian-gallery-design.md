# 聚小鲜追加图库设计

## 目标

在「聚宝金昊」项目详情页保留现有 18 张图片，并在其后追加用户提供的 22 张聚小鲜图片。

## 编排

追加部分使用喜多多详情页的纵向图片节奏，但不使用其并排或裁切变体：22 张图片全部按用户给出的顺序逐张全幅展示，并保留图片原始宽高比例。

所有图片沿用现有 `xiduoduo-gallery` 的间距与响应式规则；不改动其他作品页面。

## 验收

- 详情页原有 18 张聚宝金昊图片仍然可见。
- 22 张新图全部可加载，顺序与用户提供的文件顺序一致。
- 桌面端和移动端均无横向溢出，且图片不被裁切。
- `pnpm run build` 成功。
